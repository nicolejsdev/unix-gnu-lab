 # Portfólio Técnico – Linux & DevOps

Este é meu laboratório pessoal para documentar a jornada de estudos em sistemas **Unix**, ecossistema **GNU** e **Shell Scripting**.  
Além disso, reúne práticas avançadas em:

- **Redes**: configuração, diagnóstico e monitoramento.  
- **Segurança**: usuários, grupos, permissões e boas práticas.  
- **Firewall**: iptables e nftables para controle de tráfego.  
- **Serviços**: Samba, bancos de dados e servidores web.  
- **Automação**: rotinas com **Ansible** e scripts Bash.  
- **Versionamento**: uso de **Git** e colaboração via GitHub.  
- **Containers**: criação e gerenciamento com **Docker**.  
- **Orquestração**: implantação e escalabilidade com **Kubernetes**.  

---

✨ Este repositório funciona como um **laboratório educacional e portfólio técnico**, refletindo minha evolução em administração de sistemas, DevOps e práticas modernas de infraestrutura.
