# Editores CLI: Vim, Nano e Emacs

Cheatsheet de atalhos e comandos rapidos para edicao via terminal.

---

## Vim

### Modos
* i - Entra no modo de inserção
* Esc - Voltar para o modo normal
* : - Entra no modo de comando

### Comandos de Arquivo
* :w - Salvar
* :q - Sair
* :wq - Salvar e sair
* :q! - Sair sem salvar

### Edicao e Busca
* dd - Deletar linha
* yy - Copiar linha
* p - Colar
* /termo - Buscar termo (n para proxima ocorrencia)

---

## Nano

* Ctrl + O - Salvar arquivo
* Ctrl + X - Sair
* Ctrl + K - Recortar linha
* Ctrl + U - Colar linha
* Ctrl + W - Buscar texto

---

## Emacs

* Ctrl + X Ctrl + S - Salvar
* Ctrl + X Ctrl + C - Sair
* Ctrl + G - Cancelar operacao
